# 🌍 Wanderlust

Wanderlust is an Airbnb-inspired accommodation listing and booking web application.

The project is currently under development and is being built using Node.js, Express.js, MongoDB, and EJS.

## 🚧 Project Status

**Work in Progress**

The application is currently being developed. More features will be added as development continues.

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- JavaScript
- HTML
- CSS
- Bootstrap
